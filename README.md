# 🥛 MilkMate – Smart Milk Vendor Management System

### Smart & Simple Management for Milk Delivery Businesses

## 📌 About the Project

MilkMate is a web-based milk vendor management system developed to simplify daily dairy business operations. It helps vendors manage customers, milk deliveries, subscriptions, inventory, billing, and payments through a single platform.

## ✨ Features

- 👥 Customer Registration and Management
- 🥛 Daily Milk Delivery Tracking
- 📦 Milk Inventory Management
- 💰 Automatic Bill Calculation
- 💳 Payment Tracking
- 📊 Vendor Dashboard
- 🧾 Monthly Bill Management
- 🔔 Payment Reminders

## 🛠️ Technologies Used

**Frontend:** HTML, CSS, JavaScript

**Backend:** Python Flask

**Database:** MySQL

**Tools:** VS Code, MySQL Workbench, Git, GitHub

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/USERNAME/MilkMate.git
```

**2. Navigate to the project**

```bash
cd MilkMate
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the environment**

```bash
venv\Scripts\activate
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Configure MySQL**

- Create a database named `milk_mate`.
- Execute the SQL commands from `database/schema.sql`.
- Configure your MySQL credentials in the application using environment variables.

**7. Run the application**

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000/
```
